# Digitend / Oculus React App

React SPA с адаптивным дизайном, интерактивными компонентами и формой заявки.

## 🌐 Live Demo
https://44klic44.github.io/oculus/

## 📌 Обзор проекта
Digitend — одностраничное приложение на React с современным интерфейсом.  
Реализован адаптивный дизайн для всех устройств, интерактивное меню, попапы и форма заявки с валидацией и уведомлением после отправки.

## 🛠️ Технологии
- React (функциональные компоненты)  
- React Hooks (`useState`, `useEffect`)  
- React Router — SPA-навигация  
- CSS/SCSS — адаптивный дизайн  
- Работа с формами и валидацией  
- Анимации и всплывающие уведомления  
- GitHub Pages — деплой live-demo

## 💡 Функциональность
- Адаптивный интерфейс под мобильные и десктопные устройства  
- Интерактивное меню и попап окна  
- Форма заявки с валидацией полей и всплывающим уведомлением после отправки  
- SPA-навигация без перезагрузки страниц  
- Управление состоянием интерфейса с помощью React Hooks
